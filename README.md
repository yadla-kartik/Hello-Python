## 🛠️ Setup & Installation

```bash
# Clone the repo
git clone https://github.com/yadla-kartik/Hello-Python.git

# Create a virtual environment
python -m venv venv
source venv/bin/activate    # Mac/Linux
venv\Scripts\activate       # Windows

# Install dependencies
pip install -r requirements.txt
```

**Requirements:**
```
numpy
pandas
matplotlib
seaborn
scikit-learn
tensorflow
torch
jupyter
```
